# Mahir Jualan Produk Digital dari Nol
Landing page responsif berbahasa Indonesia, tanpa proses build. Jalankan `node server.mjs` lalu buka http://localhost:3100.

Materi adalah konsep awal. Harga, format, dan tautan pembelian belum diberikan. Tombol pembelian menampilkan informasi ketersediaan, tidak memproses pesanan atau pembayaran. Sesuaikan detail produk sebelum menggunakannya untuk penjualan. Font Google memiliki fallback lokal.
